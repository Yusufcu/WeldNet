Installation

Install WeldNet and its dependencies:

# Clone the repository
git clone https://github.com/Yusufcu/WeldNet.git
cd WeldNet

# Install dependencies
pip install -r requirements.txt

Requirements

  • Python 3.8+
  • PyTorch 2.0+
  • CUDA (optional, for GPU acceleration)

Dataset Preparation

Organize your dataset in the following structure:

data/
├── train/
│   ├── good/
│   │   ├── img1.jpg
│   │   └── img2.jpg
│   ├── crack/
│   ├── porosity/
│   └── ...
└── val/
    ├── good/
    ├── crack/
    └── ...

Each subdirectory represents a defect class.

Training

Train a WeldNet model on your dataset:

python train.py \
    --train_dir data/train \
    --val_dir data/val \
    --model_type weldnet \
    --batch_size 32 \
    --epochs 100 \
    --lr 0.001 \
    --output_dir outputs

Training Arguments

Argument Description Default
--train_dir Path to training data directory Required
--val_dir Path to validation data directory Required
--model_type Model variant (weldnet, weldnet_small, weldnet_large) weldnet
--batch_size Batch size for training 32
--epochs Number of training epochs 100
--lr Learning rate 0.001
--optimizer Optimizer (adam, sgd, adamw) adam

Inference

Single Image

python inference.py \
    --model_path outputs/best_model.pth \
    --input path/to/image.jpg \
    --class_names good,crack,porosity,slag,lack_of_fusion,undercut \
    --verbose

Batch Inference

python inference.py \
    --model_path outputs/best_model.pth \
    --input path/to/images/ \
    --class_names good,crack,porosity,slag,lack_of_fusion,undercut \
    --output results.csv

API Reference

Model Creation

from nets import weldnet, weldnet_small, weldnet_large

# Create standard model
model = weldnet(num_classes=6, in_channels=3)

# Create small model (faster)
model_small = weldnet_small(num_classes=6)

# Create large model (more accurate)
model_large = weldnet_large(num_classes=6)

Dataset Loading

from utils import create_dataloaders

train_loader, val_loader, num_classes, class_names = create_dataloaders(
    train_dir='data/train',
    val_dir='data/val',
    batch_size=32,
    input_size=224,
    num_workers=4
)

Training Loop

from utils import train_one_epoch, evaluate
import torch.nn as nn
import torch.optim as optim

criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

for epoch in range(epochs):
    train_loss, train_acc = train_one_epoch(
        model, train_loader, criterion, optimizer, device, epoch
    )
    val_loss, val_acc, preds, labels = evaluate(
        model, val_loader, criterion, device
    )
